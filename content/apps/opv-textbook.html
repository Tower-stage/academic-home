模块零 · 能级、带宽与选择性吸收标记已掌握

一句话：无机半导体靠共价键把电子铺满整块晶体，能带以 eV 计宽，于是吸收又宽又平、材料不透明；有机靠范德华力把分子粘在一起，电子仍被关在单个分子内，只剩离散的 HOMO/LUMO 能级——吸收窄而强，半透明 OPV 才成立。

0.1 两张能级图，差在电子有没有被共享

无机半导体以共价键为主。电子在整块固体里离域，波函数跨越许多原子，形成几 eV 宽的能带（下图 a 的上下两条抛物线）。宽能带意味着 E > Eg 之后态密度连续且很大：吸收一旦开始就很强，并一直延伸到紫外。光谱宽而平，材料在可见区就是不透明的。

有机固体的分子之间只有范德华力，耦合只有几十 meV，比分子内的跃迁能小两个数量级以上。所以能带没有真正形成：深处的轨道基本还是「每个分子自己的」。DOS 不是连续函数，而是一串离散能级——HOMO、HOMO−1…，LUMO、LUMO+1…，每个电子能级上再叠振动复制（下图 b 里成组出现的横条）。图注里 HOMO 那条「发虚」，指的是紧密堆积的有机晶体已经出现「似带非带」的迹象，宽度仍只有几十 meV。

0.2 带宽是分子间耦合的度量

BW ≈ 4t，　t = ⟨ψi|H|ψj⟩ t：相邻分子之间的跃迁积分。一维紧束缚链的带宽就是 4t 有机晶体 t ≈ 10–50 meV → BW ≈ 0.04–0.2 eV；共价晶体有效 t ≈ 0.5–1.5 eV → BW ≈ 2–6 eV 这是把两类材料放进同一套语言里比较，t 的定义并不严格相同；要记住的是数量级的差

吸收强度由两件事相乘决定：态密度和振子强度。四支材料的态密度都只是一条窄带，撑不起吸收；把 α 抬到 105 的是 f——分子内 π–π* 跃迁的振子强度。所以它们不是「吸收少」，而是「吸收集中在很窄的一段」。

α(E) ∝ f · g(E) f：振子强度；g(E)：态密度。无机靠 g(E) 大取胜（连续态），有机靠 f 大取胜（少数强跃迁）
一条谱线有多宽：拿 PM6 拆开看 PM6 的膜吸收从约 450 nm 拉到 680 nm，看着宽，其实只有三样东西叠在一起：① 振动复制——0-0 与 0-1 两个肩峰间距约 0.17 eV（≈1370 cm−1，C=C 伸缩）；② 单线宽度——每根复制线自己的半高宽只有 60–80 meV，由薄膜里的位点无序撑起来；③ 聚集——分子堆起来后跃迁偶极相干叠加，整包络再移位、再变形。
所以「带宽」有两层，别混着说：一根振动线 0.06–0.09 eV、一整条吸收带 0.3–0.5 eV。前者只由分子内振动与无序决定，和 Eg 无关——D18 同属 BDT 类给体、带整体蓝移约 0.2 eV，而它的单线宽度与 PM6 几乎一样。

0.3 吸收系数：为什么 OPV 只要一百纳米

T = e−αd，　A = 1 − T，　d90 = 2.303α d 为膜厚（cm）。α 用 cm−1 时，换成 nm 要乘 107：d90(nm) = 2.303×107 / α
三个词先对齐：NIR、α、d90 NIR（near-infrared，近红外）：习惯指 780–2500 nm；本书实际用的是 700–1400 nm 那一段，因为 AM1.5G 的光子有将近一半落在 700 nm 以外（光子能量低，同样的功率对应更多光子），而人眼在那里完全看不见——挡住它不损失透明度。原文那句「NIR 直接带隙无机」，指的是在近红外才起吸收、并且是直接带隙的无机半导体（窄带隙 III–V、部分硫属化合物等）。「直接带隙」这个限定不能省：间接带隙的硅要靠声子补动量，同样能量下 α 低两个数量级左右，吸收层得做到几十到几百 μm。
α：吸收系数（cm−1）。光强按 I = I0e−αz 衰减，z 的单位是 cm；它描述的是「这个波长上门窗有多严」，不是「总共吸了多少」。
d90：吸收掉 90% 光所需的厚度，d90 = 2.303/α。同族还有 d63 = 1/α（就是 1/e 穿透深度，模块三的光学计算器用的那个）和 d99 = 4.6/α。选 90% 是因为「一层就够黑」说的是这个量级；63% 只吸掉一多半，做器件不够。注意 d90 是逐波长的量：半透明的诀窍就是让 NIR 处 d90 小（吸干净）、可见处 d90 大（放过去）。

四支常用材料的峰值 α 都落在 1–3×105 cm−1（有机的一般范围是 105–106），比 NIR 直接带隙无机高 1–2 个数量级。换成「吸收 90% 需要多厚」这件事就很好懂了：

最容易混的一步α 大只说明「吸得到」。吸到之后还有解离、输运、收集（模块五），电压还要看复合（模块一）。α 高 1–2 个数量级，完全不妨碍 PCE 比硅低——这是两件不同的事。

0.7 自测

有机的 α 比无机高 1–2 个数量级，为什么 PCE 反而不如硅？

因为 α 只决定「吸收长度」。无机靠宽吸收 + 高迁移率 + 长寿命，把厚层里产生的载流子也收得出来；有机的收集长度只有 ~100 nm，所以必须薄，薄就限制了总吸收量，再叠上模块一那个 0.4–0.6 eV 的能损。α 是必要条件，不是竞争力。

把膜厚从 100 nm 加到 300 nm，AVT 和 Jsc 各怎么变？用公式说。

AVT ≈ e−αvisd，d 变三倍，透过率变成原来的三次方：若原来 αvisd = 0.2（AVT 82%），三倍后 0.6（AVT 55%），肉眼可见地变暗、变黄。Jsc 随 ANIR = 1−e−αd 上升，但边际递减（100 nm 时约 63%，300 nm 时 95%），且 FF 可能因复合变差。ST-OPV 的厚度是被「透明度」和「收集」两头夹住的。

为什么无机不能靠「把吸收带挪到 NIR」做成半透明窗？

因为它的吸收是连续的带间吸收：E > Eg 之后全部吸收，而且 DOS 随能量继续增大。要可见区透明，Eg 就得 > 1.8 eV——可那时 NIR 一个光子都吸不到。要同时在 NIR 吸收、在可见区留空窗，中间必须存在一段「真的没有态」的间隔，这正是离散能级能给、连续能带给不了的东西。

左图里把 σ 从 60 meV 拖到 250 meV，你看到什么？这对应材料的什么状态？

振动结构并成一片，HOMO/LUMO 从「一根棍」变成一条窄带——就是图注里说的「似带非带」。对应物理上分子间耦合增强或无序增大（紧密堆积的有机晶体、或者掺杂后的极化子带）。但注意：σ 到 250 meV 已经比真实有机晶体的带宽还大，属于把模型推出适用范围的演示。

模块一 · 能损（Energy Loss）标记已掌握

一句话：能损是「材料能吸收的光子能量」与「器件实际给出的电压」之间的差。它由两部分组成：辐射复合那一半物理上躲不掉，非辐射复合那一半由材料与形貌决定。

1.1 能损的定义

带隙 Eg 决定了一个光子最多能贡献多少能量（单位 eV）。但器件输出的开路电压 Voc 永远比 Eg/q 小。这个差就是能损：

ΔEloss = Eg − qVoc　　（单位：eV，因为 q=1 时数值相同） Eg 从 EQE 的起始波长换算：Eg(eV) ≈ 1240 / λonset(nm)

任何论文只要给了 EQE 和 Voc，就能算出它的能损，不需要懂合成。

1.2 辐射极限与非辐射损失

ΔEloss = ΔVrad + ΔVnr ΔVrad：辐射复合导致的下限，来自 detailed balance，物理上不可消除 ΔVnr：非辐射复合导致的额外损失，靠材料与形貌压制
项目OPV 典型值含义
ΔVrad≈ 0.25 – 0.30 VEg 越小，这一项越大。这是“天花板里的天花板”，任何材料都躲不掉。
ΔVnr0.20 – 0.45 V好器件能压到 0.20–0.25 V，差的超过 0.35 V。这才是可优化的部分。
常见误解“Voc 低是因为 Eg 低”只对了一半。Eg 低确实压低 Voc，但同时抬高 Jsc。真正值得问的是：这个器件的非辐射损失是多少？这才是同 Eg 体系之间拉开差距的地方。

1.3 非辐射损失怎么算：EQEEL

给器件通一个正向电流（暗态），它会发光。这个发光的外量子效率叫 EQEEL。它和非辐射损失是一一对应的：

ΔVnr = −kBTq · ln(EQEEL) 室温下 kBT/q ≈ 25.9 mV，所以 ΔVnr(V) ≈ −0.0259 × ln(EQEEL)

1.5 自测

某器件 Eg = 1.45 eV，Voc = 0.92 V。它的总能损是多少？先猜哪一半占大头。

ΔEloss = 1.45 − 0.92 = 0.53 eV。按 ΔVrad ≈ 0.26 V 估，ΔVnr ≈ 0.27 V，非辐射那一半略大。对应 EQEEL 约 3×10−5。

为什么不能直接把 Voc 做到接近 Eg/q？

发光和发电是同一套跃迁的逆过程。器件越容易复合发光，就越难维持高电压。辐射复合给出 detailed-balance 下限，非辐射复合再往上加一层。要做高 Voc，等于要做“发光很弱但复合更弱”的器件。这就是为什么 EQEEL 是关键证据。

Eg 从 1.35 提到 1.55 eV，Jsc 和 Voc 大致怎么动？

Jsc 下降（吸收的光子变少），Voc 上升（Eg/q 抬高，且 ΔVrad 通常略降）。总效率一般不会单调变好，中间有最优 Eg。单结的 ~30% 天花板就来自这里（详见 Sze 那一章）。

模块二 · 瞬态吸收（TA）标记已掌握

一句话：TA 是给样品打一束短脉冲“泵浦”把它激发，再用另一束“探针”看不同波长、不同延迟下它吸收变化了多少（ΔA）。从中读出激发态在多长时间内变成了什么。

2.1 ΔA 图是什么

横轴是探针波长（nm），纵轴是延迟时间（ps–ns–μs 对数），颜色是 ΔA 的大小。只有三类信号：

信号符号物理含义
漂白 bleachΔA < 0基态被抽走了，吸收变少。看它多久恢复 = 激子/极化子活多久。

① 漂白在多久内恢复？　② 有没有 CT 带、在哪？　③ 极化子信号是单分子还是双分子衰减？
问题图上怎么看对应物理量 / 为什么重要

②长波侧有没有一个弱而宽的吸收带CT 态能量 ECT。它与 ΔVnr 直接相关。这条把模块二和模块一连起来了。

2.3 时间尺度对照表

时间窗发生什么看出问题的方式
0 – 0.1 ps激发、热激子冷却多数 fs-TA 的分辨极限附近，别过度解读
0.1 – 10 ps激子扩散到给受体界面、CT 态形成、部分超快解离漂白快速衰减 + PIA 长出；界面质量在这里显形
10 ps – 10 ns自由极化子形成、迁移、早期复合极化子带建立；开始出现双分子特征

三个常见坑 ① 激发密度过高：为了信噪比加能量，结果双分子复合与俄歇过程被放大，测出来的不是工作条件下的物理。 ② 只看薄膜、不看器件：薄膜 TA 没有电极与界面，结论要小心外推。 ③ 与 EQE 不自洽：TA 说“解离效率很高”，但器件 EQE 只有 60%，那说明损失发生在收集而不是解离。

2.4 从论文里取数

做法看到 TA 图，先在纸上写三行：“漂白恢复 τ ≈ ___；CT 带在 ___ nm；衰减是单/双分子”。然后看作者的解释有没有超出这三行的证据。超出就是推测，不是数据。

2.5 自测

漂白在 2 ps 内掉了 80%，说明器件效率一定高吗？

不一定。它只说明激子在 2 ps 内大量离开基态（解离或湮灭）。还要看之后极化子信号是否持续存在到 ns–μs。解离完马上复合，器件照样低效。“解离快”和“收集好”是两件事。

论文说“我们观察到长寿命极化子，因此复合被抑制”。这句话缺什么？

缺标度分析：长寿命也可能是陷阱导致的慢而不好的过程。要证明“复合被抑制”，需要给出双分子复合系数相对 Langevin 的折减，或者给 ΔA 随激发强度的依赖关系，而不只是寿命变长。

为什么 CT 带的位置值得记下来？

因为 ECT 与 ΔVnr 相关：CT 态与基态耦合越弱、能级下移越多，非辐射通道通常越强（能隙定律）。所以 CT 带位置是你判断“这个体系 Voc 还有没有救”的第二个证据。

模块三 · 光学常数与椭偏标记已掌握

一句话：椭偏测的不是吸收，是偏振态；它据此反演出 n、k 与厚度，而 k 才是吸收。所以它是所有光学模拟的输入。

3.1 椭偏的输出

一束线偏振光斜着打到薄膜上，反射光的偏振态从「线」变成了「椭圆」。你测两个量：振幅比 ψ 和相位差 Δ。它们和界面反射系数绑在一起：

tan ψ · eiΔ = rprs rp、rs：p 与 s 偏振的复反射系数（由每层的 n、k、厚度与界面粗糙度决定）

但从 ψ、Δ 到 n、k 不是一步到位的。一条曲线里至少有三个未知数（n、k、厚度 d），所以必须先假设一个色散模型，再去拟合。这就是“非唯一解”的来源（见 3.4）。

ε1 = n2 − k2，　ε2 = 2nk，　α = 4πkλ α 是吸收系数（cm-1）。k = 0 时 α = 0：透明就是没有虚部
椭偏给你单位 / 量级你可以拿它做什么
n(λ)、k(λ)n 1.5–2.2；k 峰值 0.3–1.5喂给转移矩阵，算吸收分布与 Jsc 上限
厚度 d精度约 0.1 nm对工艺：旋涂/刮涂厚度的真实值，而不是称的溶液浓度
各向异性no 与 ne 差 0.02–0.3判断分子是 face-on 还是 edge-on（见 3.6）
粗糙层 / 混合层0.5–5 nm 等效厚度解释 k 的带边为什么“发胖”
最容易搞错的一点椭偏不直接测吸收。有人拿椭偏曲线“看吸收峰”，这是把 ψ 或 Δ 的极大值当吸收峰——只有当 n 近似常数时才勉强成立。吸收要看 α 或 k，不是看 ψ、Δ 的峰位。

3.5 色散模型选型

模型什么时候用代价 / 翻车点
Cauchy透明区（k≈0），只要 n 与厚度带边附近必然错；不能拿它算吸收
Tauc-Lorentz有带隙、要同时拿 Eg 与吸收参数多，初始值不好会给假带隙
B-spline不想假设模型，实验数据好自由度最高、最容易过拟合出物理上不存在的鼓包
EMA / Bruggeman粗糙层、混合相、孔隙等效介质一上，k 的带边容易被“抹平”
非唯一解是常态同一条 ψ、Δ 曲线，可以有多组 (d, n, k) 拟合得同样好。压它有三个办法：多角度（55/65/75°）、多厚度（同一工艺做 3–5 个厚度联合拟合）、外部约束（透射/反射谱、已知的 Eg 或带边位置）。三样都没有的拟合结果，只能当趋势看。

3.6 各向异性

共轭聚合物薄膜几乎不可能是各向同性的。分子平面取向决定了两件事：面内（in-plane）与面外（out-of-plane）的极化率不同，于是两个方向的 n、k 都不同。单轴模型给两个折射率：

no（面内，ordinary）　vs　ne（面外，extraordinary） 两者之差 0.02–0.3 都可能出现；差得越多，说明取向越明显
取向通常对应对光学的影响
face-onπ–π 堆积垂直于基底面外吸收增强，垂直入射器件里更吃香
edge-on主链平行于基底面内吸收强，但垂直入射时贡献打折
影响不处理各向异性，k 的带边会被系统性搞大：拟合器会用“更强的吸收”去补偿取向带来的偏差。结果会把 k 系统性高估。而各向异性一旦处理，往往还要上双轴模型——那就不再是 2 个参数，而是 4 个。

3.7 从 n、k 到器件：吸收与 Jsc 上限

有了每层的 (d, n, k)，用转移矩阵解出膜内的电场分布 |E(z)|²，再对每层积分：

Ai = ∫ αi |E(z)|2 dz　　（αi = 4πki/λ） 活性层的 Aactive 就是“能被利用的光”；电极、界面层、ITL 的 A 就是寄生吸收

把 Aactive(λ) 乘上 AM1.5 的光子通量再积分，得到这个厚度下的 Jsc 理论上限。把它和实测 Jsc 比，答案就分岔了：

实测 Jsc 相对上限结论
接近（差 5% 以内）光学没问题，剩下的损失在电学侧（复合、迁移率、收集）
明显偏低（差 15% 以上）光学有问题：厚度不对、寄生吸收大、或者 n/k 本身错了
光学常数计算器 · 填四个数

3.8 避坑清单

  1. 拿 ψ 或 Δ 的峰位当吸收峰。
  2. 用溶液或文献里的 n、k 代替本次薄膜的 n、k。
  3. 单角度拟合，厚度和 n 同时放开。
  4. 不报色散模型、不报 MSE。
  5. 各向同性拟合各向异性薄膜，k 带边被搞大。
  6. 粗糙层厚度自由拟合，吃掉了一部分 k。
  7. 用 EQE 反推 n、k，再用这组 n、k 预测 EQE（循环论证）。
  8. 厚度只用称量/旋涂参数估，不做椭偏或台阶仪实测。
  9. 把“吸收强”当成“收集好”：光学与电学混为一谈。
  10. 忘记入射介质与背反射：玻璃/ITO 一侧的干涉会造出假的吸收条纹。

3.9 自测

某论文说“我们的薄膜在 600 nm 吸收很强”，然后给了 ψ 谱的一个峰。哪里不对？

峰位不等于吸收峰。吸收看 α = 4πk/λ；ψ、Δ 是 n、k、厚度共同作用的结果，峰可能来自干涉或 n 的色散。要判断吸收，直接看 k 或 α。

同一批样品，作者报了面内 n 和面外 n，差 0.15。这说明了什么？又漏了什么？

说明有明显的分子取向（各向异性）。漏的是：只报 n 不报 k 的各向异性；以及如果做了双轴还该给出第三个方向。若只用各向同性模型拟合，k 会被系统性高估。

实测 Jsc 比光学算出的上限低 20%，作者归因于“材料迁移率低”。这个归因能接受吗？

不能先这么说。低 20% 先查光学：厚度对不对、寄生吸收多少、n/k 来源可靠吗。只有光学上限确认可靠之后，差的那部分才轮到电学解释。

模块四 · 化学结构标记已掌握

一句话：你不需要会合成，但必须会从结构预测性质：骨架决定能级与吸收，侧链决定堆积与形貌，分子量决定重现性。

4.1 骨架：D–A 交替

主流给体是“给电子单元（D）+ 缺电子单元（A）”交替的共聚物。D 抬 HOMO，A 压 LUMO，两者的组合把 Eg 和能级定下来。

单元角色常见代表对性质的影响
给电子单元 DBDT（苯并二噻吩）类抬 HOMO → 吸收红移、Voc 下降、空穴传输改善
缺电子单元 ABT（苯并噻二唑）、BDD（双酮类）、TT（噻吩并噻吩）压 LUMO → Eg 变小、吸收红移
抬 HOMO → Voc ↓，Jsc ↑；降 Eg → Jsc ↑，但 ΔVnr 通常 ↑ 红移不是免费午餐，每篇论文都在 Eg 和 Voc 之间来回挪

4.2 侧链：决定它能不能成膜、能不能稳定

侧链（烷基、烷氧基、烷硫基、硅氧基、支链如 2-乙基己基 / 2-癸基十四烷基）对能级影响很小，主要改溶解度、π–π 堆积距离、结晶度。

学方向侧链的杂原子与支化方式通过偶极和构象影响堆积，方向和幅度依体系而异（同一个侧链在不同骨架上可能反着来）。正确姿势是：看到侧链工程，直接去找 FF、迁移率、GIWAXS 的 π–π 间距有没有动。
旋钮主要影响论文里去找的证据
侧链溶解度、堆积、结晶度、形貌稳定性FF、迁移率、GIWAXS 的 π–π 间距与相干长度

4.3 非富勒烯受体：A–D–A 与 A–DA′D–A

类型结构骨架代表性思路
ITIC 类A–D–A（IDT 稠环核 + 端基）核决定堆积与电子迁移率，端基决定 LUMO 与吸收红边
Y6 类A–DA′D–A（稠环核 + 卤化端基）端基卤化 → LUMO 下移、红移、Jsc 提升；核决定形貌与稳定性
训练法读摘要时看到“我们引入 X 基团”，先合上论文，写一句预测：Eg 会___，Voc 会___，FF 会___，形貌证据应该是___。然后翻表核对。

4.4 自测

某工作把给体上的烷氧基换成烷硫基，PCE 从 15.2% 提到 16.1%，Voc 基本不变。你最先怀疑哪一项？

不先去猜能级，而先看 FF 与形貌证据：Voc 没动，说明能级/非辐射损失没大改；提升大概率来自堆积改善 → 迁移率与 FF。这是典型的侧链 → 形貌 → FF 路径。

为什么“同一材料不同批次效率差 1%”是结构问题，也是方法问题？

分子量/PDI 分布不同 → 成膜与相分离尺度不同 → FF 波动。这是 OPV 的结构性弱点，也是为什么很多“新纪录”难以复现。读到没报批次与分子量的高 PCE，先打一个问号。

一个体系 Eg 降到 1.25 eV，Jsc 涨了 2 mA/cm²，但 PCE 没涨。最可能的账怎么算？

Voc 掉得太多，且 ΔVnr 很可能同时变大（能隙定律）。所以在低 Eg 端，红移换电流通常不划算；单结存在最优 Eg 就来自这里。

模块五 · 输运与复合标记已掌握

一句话：给体稀释后，输运与复合一起变坏，最后落在填充因子上。本节把电导率、复合机制、收集效率三件事连起来，源头是 Adv. Mater. 2026 的 donor-diluted 研究（PM6:Y12，给体从 1% 到 45%）。

5.1 输运：电导率、DOS 与逾渗模型

本节覆盖六个模型。它们从 J-V 曲线出发，先提电导率，再定 DOS 形状，再用跳跃与逾渗解释，最后落到迁移率。

模型 1 · 有效电导率 σoc（Eq 1）

一句话：σoc 是活性层开路附近的纯输运电导率，等于 J-V 斜率扣除复合电阻后的量。

L / σoc = [ dV/dJ − nid·kBT / (e·Jrec) ]J=0

怎么测试/测量：用完整太阳能电池，源表扫 J-V 曲线，配太阳模拟器。

  • 原始数据是 J 对 V 曲线，重点看开路点 Voc 附近的斜率 dV/dJ。
  • 先做外串阻校正：大正偏压下拟合 dV/dJ，得串联电阻 Rs，再扣掉。
  • 要备好厚度 L、开路复合电流 Jrec（约等于光生电流）、理想因子 nid。
外串阻校正 大正偏压下输运电阻可忽略，dV/dJ 只剩外串阻 Rs。拟合这一段得 Rs，再从 J-V 扣除。Eq 1 为清晰省略了这一步。

怎么得出：dV/dJ 在 J=0 处含两项：输运电阻 L/σoc，加复合电阻 nid·kBT/(e·Jrec)。

后者是"电导率无穷大"假想器件的倒数斜率，代表无输运损耗的曲线斜率。扣掉它，剩下纯输运电阻，再除以 L 得 σoc。

拟合参数：nid（由 suns-Voc 得）、Rs（由大正偏压得）、L（轮廓仪或椭偏测厚）。

假设：近 Voc 时复合电阻与输运电阻线性叠加，Jrec≈Jph。

可视化性：高。画一条 J-V 曲线，标两条切线：真实斜率与"无穷电导率"斜率，两斜率之差即输运项。再画 σoc 对温度或光强的散点。物理直觉直接：斜率等于电阻。

复现难度：中。仪器是标准太阳电池测试台加源表，普通实验室都有。变温要 cryostat，属较贵设备。软件 Python + numpy 足够，数值微分加线性拟合。不做合成的测量组能复现，只需拿到器件。

模型 2 · DOS 特征能量 EU（suns-Voc）

一句话：EU 是 DOS 的局部斜率，量度能隙内每个能量处的无序程度。

怎么测试/测量：测光强序列乘温度序列的 suns-Voc。

  • 用中性密度滤光片做一串光强，每个光强下测 Voc。
  • 同一组在多个温度重复，形成二维矩阵。
  • suns-Voc 只变光强、不变偏压，避免器件退化。

怎么得出：光强依赖 Voc 给出复合理想因子 nid（Voc ∝ nid·kBT/e · ln I）。

温度依赖的 nid 代入多陷获-释放（MTR）模型，反演 DOS 形状。

对每个能隙深度 Eg − eVoc 算局部斜率 EU。EU 恒定是纯指数 DOS；EU 随深度增大是幂律 DOS。

本文 PM6:Y12 的 EU 随深度增大，判为幂律 DOS。

可视化性：中高。画 EU 对 (Eg−eVoc) 曲线，或归一化 DOS 对能量。斜率即无序，直觉中等。

复现难度：中高。变温加变光强是门槛，cryostat 较贵。软件 Python 够用，但 MTR 反演要自己写数值程序。测量组可复现，依赖拿到器件。

模型 3 · Miller–Abrahams 跳跃（Eq 2）

一句话：跳跃速率由隧穿项与热激活项共同决定。

νij = ν0·exp(−u)；u = 2rij/α + ΔEij/(kBT)（向上跳）；u = 2rij/α（向下跳）

怎么测试/测量：不是直接测量，是理论模型，用于定性解释 σoc 的温度依赖。

输入量：位点间距 rij、局域长度 α、位点能量差 ΔEij、温度 T。

怎么得出：向上跳（Ei<Ej）要热激活，乘 exp(−ΔEij/kBT)。向下跳只靠隧穿，无温度项。

u 是统一跳跃参数，越大速率越低。距离项是隧穿贡献，Boltzmann 项是热激活。

本文用法：在 EU 相近的能隙深度，各组分 Boltzmann 项相当，故输运差异主要来自隧穿与空间项，引出几何逾渗。

可视化性：中。画跳跃速率对温度（Arrhenius 图）或对位点间距。是定性参考模型，直觉中等。

复现难度：低。纯理论，不需要仪器。可做动力学蒙特卡洛（KMC）模拟，Python 即可。

模型 4 · 逾渗模型（Eq 3）

一句话：电导率在阈值 fc 之上按 (f−fc)p 幂律增长，饱和于 σmax。

σ = min( σmin·(f − fc)p, σmax )

怎么测试/测量：用模型 1 得不同 PM6 分数在 300 K、固定能隙深度 Eg−eVoc=0.66 eV 的 σoc。

固定温度与固定能量截面，排除能量无序影响，只留空间连通性。

怎么得出：把 σoc 对给体分数 f 拟合 Eq 3，固定 p=2。

拟合参数：σmin、fc、σmax。p=2 是三维逾渗网络的理论临界指数。

fc≈0，说明链纠缠保证连通。图 5c 里 μeff 用同一模型拟合，p=1.8 作自由参数，落在三维范围。

阈值≈0 的读法 fc 接近零不代表没有逾渗，而是给体链纠缠与混合网络在极低分数仍保连通。作者建议把低电导率叫"强拓扑受限"。

可视化性：高。σoc 对 PM6 分数散点，叠加 (f−fc)² 拟合线。阈值加幂律加饱和，直觉很强。

复现难度：低到中。只需 σoc 数据，scipy 的 curve_fit 即可。数据来自模型 1。

模型 5 · SCLC 迁移率（Mott–Gurney 与 Mark–Helfrich）

一句话：用单载流子器件的空间电荷限制电流测迁移率，电子用 Mott–Gurney，空穴用 Mark–Helfrich。

Mott–Gurney：J = (9/8) ε ε0 μn V² / L³
Mark–Helfrich：J ∝ Vl+1，l = Tc/T

怎么测试/测量：做单电子与单空穴器件。

  • 电子-only：如 ITO/ZnO 或 PEIE/活性层/Ca-Al。
  • 空穴-only：如 ITO/PEDOT:PSS/MoO3/活性层/MoO3/Ag。
  • 暗态扫 J-V，log J–log V 上找 SCLC 区（斜率≈2 或 >2）。
  • 电极要阻挡另一载流子，保证单载流子注入。

怎么得出：Mott–Gurney 由 J 对 V² 斜率提 μn，假设高斯 DOS、迁移率不依赖电场。

Mark–Helfrich 由 log-log 斜率和截距提 μp，假设指数尾巴 DOS，特征温度 Tc。

本文电子器件符合 Mott–Gurney，空穴器件偏离 V² 关系、符合 Mark–Helfrich，判为混合 DOS。

可视化性：中高。画 log J 对 log V，斜率 2 与 >2 一眼区分两模型。直觉中等。

复现难度：中。单载流子器件要额外制备，做器件组容易，纯测量组要现成样品。仪器是普通源表。软件 Python 够用。

模型 6 · 有效迁移率调和平均（Eq 4）

一句话：μeff 是电子与空穴迁移率的调和平均，由较慢一方主导。

μeff = 2 / ( μn−1 + μp−1 )

怎么测试/测量：取模型 5 的 μn 与 μp，直接代入 Eq 4。

怎么得出：μeff = 2 μn μp / (μn+μp)。当 μp≪μn，μeff≈2 μp，慢载流子主导。

本文 μeff 随 PM6 分数下降，与 σoc 同服从逾渗模型（p=1.8），把宏观电导率与微观迁移率连起来。

可视化性：中。画 μeff 对 PM6 分数散点加逾渗拟合线，与 σoc 并排对比。"短板主导"直觉强。

复现难度：低。只需 μn、μp 数据，一行代码。

推荐总图 一张三面板图：σoc 对 PM6 分数散点加 (f−fc)² 线；μeff 对 PM6 分数同拟合；log J–log V 双对数图区分 Mott–Gurney 与 Mark–Helfrich。

5.2 复合：Langevin 与 Smoluchowski

本节回答载流子怎么消失。作者用 PL 瞬态和 TDCF 两套方法测复合，结论：高给体分数是 Langevin 型，低给体分数是 Smoluchowski 型（扩散限制相遇）。

模型 1 · PL 瞬态测复合

一句话：连续激光激发后 1 ns 内快速关断，看发光衰减，反推载流子浓度和总复合率。

怎么测试/测量：用 CW 激光打器件，稳态后瞬间关断（约 1 ns），记录 PL 衰减，原始数据是 PL(t) 曲线。

  • 要分开两个成分：低于 10 ns 的局域激子快衰减，和 μs–ms 的非孪生复合慢衰减。
  • 激子衰减与激光通量无关；非孪生复合与通量有关，靠变通量分开。

怎么得出：PL(t) = krad·n²(t)，所以 PL 衰减直接给 n(t)，再由 R(t) = −dn/dt 得总复合率。krad 是辐射复合系数。

好处：PL 在复合发生的地方、发生的时候观测，而不是事后抽存活载流子。

可视化性：高。PL(t) 衰减曲线加双对数斜率，一眼看到快/慢两段。

复现难度：中。要时间分辨单光子计数（TCSPC）加快关断激光，光学实验室常规，不做合成也能做（只要给薄膜或器件）。

模型 2 · 复合阶数 δ

一句话：δ 是复合率随载流子浓度的幂次，δ=2 是双分子（Langevin），δ>2 是陷阱辅助。

δ = EU/(kBT) + 1；　n(t) ∝ t−1/(δ−1)；　PL 指数 = −2/(δ−1)

怎么得出：对指数 DOS 的陷阱辅助复合，δ 由特征能量 EU 决定。

  • δ=2（EU≈kT，无陷阱）→ PL 指数 −2，是最简单的双分子情形。
  • δ=3（EU=50 meV）→ PL 指数 −1。

本文高给体分数在 μs→ms 交界 δ 略小于 2；长时 PL 指数约 3，意味着 EU<kT、δ 应回到 2——矛盾，作者据此改提 Smoluchowski（见模型 5）。

可视化性：中。双对数 PL 的斜率就是 δ，但不同时间窗要分开看。

复现难度：低。纯分析，从 PL 衰减取斜率。

模型 3 · Langevin 复合与缩减因子 γ（Eq 5）

一句话：库仑吸引下电子空穴相遇即复合，速率正比迁移率之和；γ 是实测与 Langevin 预测的比值。

k2 = γ · e(μn + μp) / (ε·ε0)

怎么测试/测量：k2 来自 PL 和 TDCF（1 太阳等效），μ 来自 SCLC，ε 查表或椭偏。

怎么得出：γ = k2,实测 / kL。高 PM6 分数 γ<1（复合比 Langevin 慢，正常）；低 PM6 分数 γ 接近甚至超过 1。

γ>1 不物理 复合不可能比 Langevin 更快。作者自己点破：这是强行套 Langevin 框架的假象——低给体分数下复合机制已经变成 Smoluchowski 型，Langevin 公式不再适用，γ 失去意义。

可视化性：高。γ 对 PM6 分数散点，一条越低越怪的曲线。

复现难度：低。要 k2、μ、ε 三个数，Python 一行。

模型 4 · CT 再解离缩减因子 γct = 1 − ηdiss

一句话：CT 态会再解离回自由载流子而不是复合掉，所以复合被压低，γct = 1 − ηdiss。

怎么测试/测量：TDCF 在 Voc 处测解离效率 ηdiss（2%、5%、45% 三个组分）。

怎么得出：Blom 组机制：CT 态再解离 → 有效缩减 γct = 1 − ηdiss。15% 以上 PM6，γct 与实测 γ 同量级，说明再解离能解释高给体分数下的低复合。

5% 处偏离，可能是 TDCF 低估载流子浓度 → 高估 k2（低连通性下抽出效率差）。

可视化性：中。γ 与 γct 叠一张图，看两条线是否同量级。

复现难度：中。要 TDCF，比 PL 更小众。

模型 5 · Smoluchowski 复合（t−3/2，Eq 6）

一句话：载流子要先扩散穿过空间才相遇，复合率随时间变慢，长时极限 R(t) → t−3/2。

R(t) → t−3/2（t→∞）；　n(t) ∝ t−1/2；　k2(t) ∝ t−1/2；　γapp(t) ∝ t−1/2

怎么得出：解扩散方程的长时解，得 R(t) → t−3/2。这个标度独立于能量无序、陷阱分布、跳跃参数——是空间扩散限制相遇的普适统计。

本文所有器件在长时（≳10 μs）复合率都收敛到 −3/2 斜率，1% 和 2% 组分全程都是它。

关键判断 t−3/2 是硬物理（扩散方程通解），Langevin 的 γ 是套框架。低给体分数时，说复合是 Smoluchowski 型比说 γ 超标诚实。

可视化性：高。R(t) 双对数图上斜率 = −3/2 的直线，是所有器件长时都收敛到的那条线。

复现难度：低。只要 PL 瞬态长时数据，取双对数斜率。

模型 6 · TDCF 与 PL 的差异

一句话：PL 连续监测辐射复合，TDCF 只测延迟后仍存活、能被抽出的载流子。

怎么得出：PL 对局域复合敏感，主导早期动力学（Langevin 型）；TDCF 在延迟后选择性测存活载流子，低连通体系会漏掉已复合的载流子，从而高估复合系数。

所以对低给体分数 PL 更可信；对好器件 TDCF 较准。

可视化性：中。两方法 k2 并排对比。

复现难度：中。TDCF 要专用装置。

5.3 收集效率：α、β 与填充因子

本节把输运和复合并起来，解释它们怎么吃掉填充因子。作者用两个自定义品质因数 α、β 把输运电阻折算进理想因子，再用 Green 方程预测 FF。

模型 1 · 品质因数 α（Eq 7）

一句话：α 是输运电阻在开路附近造成的额外电压降，让 J-V 变平。

α = e·L/(kBT) · Jgen/σoc

怎么测试/测量：Jgen（短路附近光电流）、σoc（5.1 节）、L（膜厚）。

怎么得出：α 正比产生电流、反比电导率。σoc 小（低给体分数）→ α 大 → 光照 J-V 在 Voc 处被压扁 → FF 掉。表观理想因子变成 nid + α。

α 的局限 α 只在 Voc 定义，不描述最大功率点（mpp）的曲率，而 FF 在 mpp 决定，所以 α 系统性地高估 FF。

可视化性：中。α 对 PM6 分数；或 J-V 在 Voc 处的两条切线（真实 vs 无穷电导率）。

复现难度：低。纯计算，输入 σoc、Jgen、L。

模型 2 · 品质因数 β（迭代，Eq 9）

一句话：β 是 α 的推广，可在任意电压（尤其 mpp）算，用来更准地预测 FF。

β = α · [ voc(voc+1) / nid ] · [ (nσ − 1) / ln(voc + 1) ]；　voc = e·Voc / ( (nid + β)·kBT )

怎么得出：把 α 换成 β 后，表观理想因子变成 nid + β。β 需要迭代：初值 α → 代入算 voc → 更新 β → 再代入，直到收敛。需要 nid、nσ（电导理想因子）、α、Voc 四个量。

可视化性：低。本身是迭代参数，没有单一直观图；但 β 预测的 FF 贴实测这条线可视化很强。

复现难度：低。Python 循环几次就收敛。

模型 3 · Green 方程（Eq 8）

一句话：Green 方程是经验式，把归一化开路电压 voc 换成 FF。

FF = ( voc − ln(voc + 0.72) ) / ( voc + 1 )；　voc = e·Voc / ( napp·kBT )

怎么得出：Green (1982) 的经验式，napp 是表观理想因子（含 α 或 β）。把 α 或 β 塞进 napp，就能预测 FF。

关键判断 α、β、Green 方程都是作者定义的品质因数或经验式，不是微观定律。价值在于：把输运电阻统一折算成理想因子，从而只用一条 J-V 就能预测 FF。能用，但不神秘。

可视化性：高。一张图：实测 FF 对 PM6 分数 + α 预测线（虚线）+ β 预测线（实线）。β 线贴实测，α 线偏高。

复现难度：低。要 σoc、Jgen、nid、Voc，Python 全搞定。
